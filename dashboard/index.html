Your agent will get tricked. Your wallet won't.

Leash is a NEAR wallet for AI agents. You choose who it can pay, how much, and when it has to ask you first. The rules run on-chain, so an agent that gets tricked still can't break them.

What you see is not what your agent reads

AI agents read web pages, emails, documents and messages that anyone can write. Text a person never sees, like a hidden block on a web page, still reaches the agent. If that text sounds like an instruction, the agent may follow it. This is called prompt injection, and no filter catches every case.

How it works

Three layers sit between your agent and your money. The first two reduce how often a fooled agent gets anywhere. The third is the guarantee.

  1. Injection filter

    Before the agent reads a page, two detectors scan it: Prompt Guard 2 for blunt jailbreaks, and a policy check that catches instructions dressed up as normal notices. Flagged pages are blocked or come with a warning.

  2. A key that can only ask

    The agent signs with a NEAR function-call key that can call one thing: request_payment on your Leash. It can't send NEAR directly, change rules or touch other contracts.

  3. Rules in the contract

    Every request is checked on-chain against your rules: approved recipients, a cap per payment, a daily limit, and a threshold above which you approve by hand. You can pause the agent at any time.

    Questions

    What happens if the injection filter misses an attack?

    Nothing changes for your money. The filter only reduces how often a fooled agent reaches the wallet. The contract still checks every request against your rules, and the demo shows it blocking attacks with the filter switched off.

    Can the agent change its own rules?

    No. The agent's key can only call request_payment. Changing limits, approving held payments, editing recipients, pausing and withdrawing are owner-only, and the contract checks who is calling.

    What if the agent's key is stolen?

    The thief gets the same limits the agent had: approved recipients only, capped amounts, and nothing above your approval threshold without you. Pause the wallet from the dashboard and switch to a new agent account.

    Is Leash audited? Can I use it with real money?

    Not yet. Leash is a hackathon project running on NEAR testnet, and the contracts have not been audited. Don't use it with real funds.

    Does it work with any AI agent?

    Yes, as long as the agent can make a NEAR function call. The client in the repo is JavaScript; the contract itself doesn't care which model or framework sits behind the key.
